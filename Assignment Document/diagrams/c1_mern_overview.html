The MERN Stack
M
MongoDB — Database
NoSQL document database that stores data as flexible JSON-like documents.
E
Express.js — Backend
Minimal Node.js framework used to build the REST API and middleware.
R
React — Frontend
Component-based library for building the interactive user interface.
N
Node.js — Runtime
JavaScript runtime that executes the server-side application code.
The four JavaScript-based technologies that together cover every layer of the application.
