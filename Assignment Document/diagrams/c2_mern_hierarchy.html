MERN Application Hierarchy
Client (Browser)
React 19 + Vite + Tailwind CSS — user interface
⇅HTTP request / JSON response (Axios)
Server
Node.js runtime  →  Express framework  →  REST API (routes, controllers, services)
⇅Mongoose ODM (queries)
Database
MongoDB — collections of documents
Requests flow down from the browser to the database and responses flow back up the same path.
