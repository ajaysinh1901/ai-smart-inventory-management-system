Introduction

The Problem

  • Millions of small retail businesses (kirana stores, traders, wholesalers) still manage stock with paper registers or basic spreadsheets.
  • Manual billing leads to GST calculation errors, lost invoices, and compliance headaches.
  • Customer credit ("udhaar") is tracked in physical khata books — entries get lost, disputes arise, and payment reminders are forgotten.
  • Shop owners have no visibility into which products sell fast, what to reorder, or how much stock is lost to shrinkage.
  • Existing software is either too expensive, too complex, or not built for the Indian small-business workflow.

Solution

Proposed System

  • A full-stack web application built on the MERN stack — MongoDB, Express.js, React, Node.js.
  • Single platform covering the complete retail workflow: stock in → sell → bill → collect → analyse.
  • AI-assisted decisions: demand forecasting, smart alerts and an in-app help chatbot.
  • Automation: cron jobs generate periodic reports and raise smart stock alerts without user effort.

Module 1

Inventory & Product Management

  • Product catalogue with categories, pricing, GST rate and unit of measure (pieces, kg, grams, litres).
  • Real-time stock levels updated automatically on every sale and purchase.
  • Low-stock detection with configurable reorder thresholds per product.
  • Stock adjustments module records shrinkage — damage, theft, expiry, counting errors — with reasons.
  • Precise quantities: weight stored with dedicated utilities to avoid floating-point errors.

Why it matters

The shop owner always knows what is in stock, what is running out, and where stock is being lost — replacing guesswork with data.

Implementation highlights

• Mongoose Product & StockAdjustment models
• Zod-validated REST endpoints
• Money & weight stored as Decimal128 for accuracy
• Shrinkage page visualises losses by reason

Module 2

Quick Sale & GST Billing

  • Designed for speed: search a product, enter weight or amount, and the bill builds itself.
  • Amount-first mode: customer says "₹50 of sugar" — the system back-calculates the quantity.
  • Tare-weight support for weighing with containers.
  • Automatic GST calculation per line item based on each product's tax rate.
  • Payment modes: cash, UPI / online, or credit (goes straight to the customer's khata).
  • PDF invoice generated server-side with PDFKit, including a UPI QR code for instant payment.

Module 3

Digital Khata — Customer Credit Ledger

  • Replaces the traditional paper khata (udhaar) book used in Indian shops.
  • Every credit sale automatically creates a khata entry against the customer.
  • Running balance maintained per customer — credits and repayments in one timeline.
  • Repayments can be recorded partially or fully, with full history preserved.
  • Owner sees total outstanding credit across all customers at a glance.

Data model

Customer ← linked to → KhataEntry (type: credit / payment, amount, linked sale, note, date) with a service layer that keeps balances consistent.

Impact

No more lost entries or disputes — both the shopkeeper and the data agree on exactly who owes what.

Module 5

OCR Bill Scanner

  • Adding 50 products from a supplier bill by hand is slow and error-prone.
  • The owner simply photographs the bill and uploads it on the Scanner page.
  • Tesseract.js performs optical character recognition on the server.
  • The OCR service parses product names, quantities and prices from the extracted text.
  • Parsed items are presented for review and one-click import into inventory.

Engineering quality

Security & Reliability

🔑 Authentication

JWT-based sessions with bcrypt-hashed passwords; protected routes via auth middleware on both API and UI.

🛡️ Input Validation

Every endpoint validated with Zod schemas through a central validation middleware — malformed data never reaches the database.

🚦 Rate Limiting

express-rate-limit protects login and API endpoints from brute-force and abuse.

💰 Money Accuracy

All currency and weight values use Decimal128 / decimal.js — no floating-point rounding errors in bills or GST.

🧪 Testing

Node test-runner smoke tests and end-to-end API tests verify endpoints, status codes and GST math.

⚠️ Error Handling

Central error middleware on the server and React Error Boundaries with toast feedback on the client.
